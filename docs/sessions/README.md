# Récits de session — journal de route StatCheck

Ce dossier raconte **ce qu’on a fait, pourquoi, ce qu’on a appris**, en langage simple.

## Deux pistes complémentaires

| Dossier | Rôle |
|---|---|
| **`docs/sessions/`** (ici) | Récit humain : contexte, résultats, interprétation, suite, leçons |
| **`docs/audit/`** | Trace technique : commandes, listes de fichiers, décisions normatives précises |

On continue à écrire les audits techniques à chaque session structurante.  
**En plus**, on écrit (ou on enrichit) un récit dans ce dossier.
